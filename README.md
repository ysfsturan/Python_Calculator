# 🧮 Python Calculator

Python'da temel programlama pratiği için yazılmış, ek kütüphane gerektirmeyen basit bir konsol hesap makinesi.  
*(A simple, dependency-free Python console calculator built for practicing programming fundamentals.)*

## ✨ Neler Yapabiliyor? / Features

- Toplama (`+`), Çıkarma (`-`), Çarpma (`*`), Bölme (`/`)
- Üs alma (`**`), Mod / Kalan (`%`) ve Karekök (`√`)
- Sıfıra bölme ve hatalı sayı girişlerinde uyarı (`try / except`)
- Nokta (`3.5`) veya virgül (`3,5`) ile ondalık sayı desteği

## 📚 Kullanılan Temel Konular

- Fonksiyon tanımlama (`def`)
- Menü için `while True` döngüsü ve `if / elif / else` kontrolleri
- Hata yakalama (`try / except ValueError`)

## 🚀 Çalıştırma / Usage

Bilgisayarınızda yalnızca Python 3 kurulu olması yeterlidir:

```bash
python calculator.py
```

Testleri çalıştırmak için:

```bash
python -m unittest test_calculator.py -v
```
